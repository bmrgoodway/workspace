# 서버 함수

- 이 앱의 '서버 함수 자동 배포'가 켜져 있으면, 함수 폴더의 코드를 고쳐 `main` 에 올릴 때(push) GitHub Actions **서버 함수 검사·배포**(`.github/workflows/functions-check.yml`)가
  형식 검사(`deno check`) 뒤 BMR APPS 허브를 통해 **바뀐 함수만** 자동으로 배포합니다. 저장소에 비밀값은 필요 없습니다.
- 기본 함수는 `workspace-fn/` 입니다. 새 함수는 `workspace-<이름>/index.ts` 폴더를 만들면 처음 push 때 새로 만들어집니다
  (이름 끝부분은 영문 소문자·숫자를 하이픈으로 이어 20자까지, 추가 함수는 앱마다 3개까지).
- 결과(함수별 버전, `/health` 응답)는 Actions 실행 화면의 Summary 에 나옵니다. 모든 함수를 다시 배포하려면 Actions 탭에서 **Run workflow** 를 누르세요.
- 자동 배포가 꺼져 있으면 배포되지 않고 Summary 에 안내가 나옵니다. 허브 → 내 서비스 → 앱 정보 → **개발자 셀프서비스**에서 켜 달라고 요청하세요 (관리자가 1클릭 승인).
- 진입점은 각 폴더의 `index.ts` 이고, 그 폴더 안의 파일만 함께 올라갑니다.
- 함수 비밀값(`WORKSPACE_…`)은 개발자 셀프서비스에서 직접 넣고 지웁니다 (값은 쓰기 전용). 로그도 같은 곳의 **로그 보기**에서 봅니다.
- 안 쓰는 추가 함수는 셀프서비스에서 지우고 이 폴더도 지우세요.
